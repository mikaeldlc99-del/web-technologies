🗄️ Gestión y Persistencia de Datos Esta sección representa el núcleo de almacenamiento de la aplicación mediante una base de datos relacional SQL. Aquí se detalla el diseño del modelo entidad-relación, la creación de tablas, llaves primarias/foráneas y la escritura de consultas (Queries) optimizadas. En este apartado se gestionará de forma segura toda la información persistente del sistema, como registros de usuarios, configuraciones y datos del negocio.
