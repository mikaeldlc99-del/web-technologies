EXPRESS

🚀 Servidor y Desarrollo del Backend Aquí se expone la arquitectura del servidor construida con Node.js y el framework Express. Esta capa actúa como el puente inteligente entre el usuario y la base de datos. En esta sección se configuran las rutas de nuestra API REST, los middlewares de seguridad, el procesamiento de peticiones HTTP (GET, POST, PUT, DELETE) y la lógica de negocio encargada de recibir, procesar y responder a las demandas del frontend.
