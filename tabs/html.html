🌐 Estructura y Semántica Web Bienvenidos a la sección fundacional del proyecto. En este apartado se establece el esqueleto semántico de la aplicación utilizando HTML5. Aquí se estructuran los contenedores principales, formularios de captura de datos, tablas de visualización y la jerarquía de contenidos que posteriormente interactuarán con el cliente y el servidor. El objetivo es garantizar un código limpio, accesible (SEO friendly) y correctamente preparado para ser manipulado dinámicamente.
